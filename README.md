# Aircraft Wastewater Virome

This repository contains the analysis scripts and influenza A sequencing data associated with the study:

**Aircraft Wastewater Virome Surveillance from Domestic and International Flights Reveals Viral Diversity Among Travellers: A Proof-of-Concept Study from Gujarat, India**

## Influenza A Subtype Analysis

Influenza A-positive reads were further analyzed using the `iav_serotype` tool for read-level subtype classification. The corresponding FASTQ reads are provided in this repository to support transparency and reproducibility of the reported influenza subtype-associated findings.

## Study Overview

This study investigated viral diversity in wastewater associated with domestic and international flights at Ahmedabad Airport, Gujarat, India, using probe-capture viral enrichment and next-generation sequencing.

The study identified a broad range of respiratory, enteric, and other clinically relevant viruses and demonstrates the potential of aircraft wastewater virome surveillance for monitoring viral diversity among highly mobile populations.
